# Hi, I'm Lex 👋

I'm a Computer Science undergrad at **Nanyang Technological University (NTU)**, pursuing a B.Eng (Computer Science) and M.Sc. Technology Management as a **REP Scholar**. I recently wrapped up an exchange year at **UC Berkeley** (GLOBE programme).

I like working at both ends of the stack: low-level systems and security (reverse engineering, firmware analysis) and full-stack AI products that people actually use.

## 🛠️ What I've been working on

- **AI Enablement Office, CPF Board** (2026): built *SlideCentral* (AI-assisted slide generation) and *SkillsCentral* (a platform-agnostic AI skills marketplace) with Next.js, Node.js and MongoDB, deployed on AWS with Docker. Also worked on a browser extension for moving AI skills between LLM tools, and documented its security and data-access boundaries.
- **DSO National Laboratories** (2025): extended a Ghidra-based firmware analysis tool, building a database of network protocol formats (DNS, IPv4/6, IKE) to help identify parser functions in binaries for vulnerability research.
- **SCALE @ NTU** (2024): built 3D generative pipelines (Shap-E, Magic3D) and evaluated LLMs on generating algorithmic pseudocode.
- **UC Berkeley** (2025–26): coursework in Algorithms, AI, Computer Architecture, Networks, Cybersecurity and Compilers, plus a full-stack debating platform built at CalHacks.
